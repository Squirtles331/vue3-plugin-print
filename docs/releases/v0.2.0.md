# v0.2.0

发布日期：2026-08-11

## 发布内容

v0.2.0 增强了浏览器打印的可验证性和模板运行时链路，提供更严格的预检、可追踪的数据绑定、模板仓储与发布验证能力。

> 此版本使用 `TemplateDocument v1`。后续开发版本已升级到 v2 且不提供自动迁移，升级前请阅读[开发中版本说明](/releases/unreleased)。

## 新增

- 独立 Vue 3 浏览器打印模板设计器，覆盖十类元素、属性编辑、JSON 数据绑定、运行时预览和打印。
- 本地模板库、导入导出、起始模板、元素预设，以及模板删除和清空能力。
- GitHub Pages 构建、CI、浏览器打印隔离回归测试和发布验收文档。
- 严格打印预检、运行时数据路径绑定及问题定位、模板纸张 CSS、资源就绪等待和多页表格的受控元素重复。
- 打包消费者入口验证与发布标签—包版本一致性校验。

## 优化

- 默认阻止缺失绑定、越过模板安全区、空条码/二维码和不可加载图片的打印。确实需要输出不完整模板时，可显式设置 `printPolicy: { allowIncomplete: true }`。
- 打印 CSS 按模板的毫米纸张尺寸生成；模板边距作为安全区参与预检。打印机的物理不可打印边距仍须在目标设备校准。
- 多页表格只重复显式标记 `repeatPerPage` 的元素，不会为已经没有数据的表格生成空白后续片段。

## 安全

- 间接依赖 `nanoid` 升级至 3.3.18，`postcss` 升级至 8.5.26，以修复审计发现的问题。

## 已知限制

- 不提供 PDF/图片导出、静默/云打印、设备级打印控制、服务端渲染和协作能力。
- 建议在桌面版 Chrome 或 Edge 中使用，并在原生打印对话框选择实际大小、关闭浏览器页眉页脚。
