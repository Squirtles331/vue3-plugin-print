# 下一版本（开发中）

本页记录 `main` 分支尚未发布的变更。内容可能在正式发布前调整；请勿把它当作已发布版本的兼容性承诺。

## 破坏性变更

- 模板持久化和运行时输入固定为 `TemplateDocument v2`（`schemaVersion: 2`）。
- `TemplateDocument v1` 及已移除的字段别名不再接受，导入、仓储读取和组件传入时都会返回校验错误。
- 包不提供自动迁移或兼容层。使用 v1 模板的业务应先在自身系统中完成数据转换，或基于 v2 重新创建模板，再升级到下一版本。

## 功能与体验

- 完善表格运行时分页和摘要统计。
- 优化属性面板、多选提示以及撤销/重做交互。
- 源码、测试、构建脚本和 VitePress 配置迁移到严格 TypeScript；Vite 开发与构建阶段自动导入 Vue、Pinia API，并由生成的 `auto-imports.d.ts` 提供类型声明。

自动导入仅用于本仓库源码开发，不会修改 npm 包的公开导出或向宿主应用注入全局变量。
