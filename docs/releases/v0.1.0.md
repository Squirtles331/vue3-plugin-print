# Print Template Studio v0.1.0

## 首个开源版本

v0.1.0 提供浏览器中的模板设计、版本化 JSON 模板交换、运行时业务 JSON 绑定、预览和浏览器原生打印。模板保存于当前浏览器，本版本不需要服务器或账号。

## 包含内容

- 十类设计元素与页面、排版、表格、条码/二维码和标签网格属性。
- 模板新建、保存、重开、删除、清空本地库、导入导出和元素预设。
- 缺失数据显式提示、表格分页、共享预览/打印渲染与隔离打印 iframe。

## 支持与限制

- 支持最新桌面 Chrome 和 Edge；请在原生打印对话框中选择 100%/实际尺寸，并校准实际打印机边距。
- 不包含 PDF/图片导出、静默/云打印、打印队列、设备参数控制、账户同步、协作、npm 组件包或 Web Component。
- 本地存储可能被浏览器清理；请导出重要模板 JSON。

## 升级与反馈

这是第一个版本，没有旧版迁移步骤。请通过 GitHub Issues 提交可复现的问题或功能建议；安全问题请按 [SECURITY.md](../../SECURITY.md) 私下报告。
