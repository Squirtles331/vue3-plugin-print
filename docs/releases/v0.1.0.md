# v0.1.0

发布日期：2026-08-10

## 发布内容

这是首个开源版本，提供浏览器中的模板设计、版本化 JSON 模板交换、运行时业务 JSON 绑定、预览和浏览器原生打印。

## 新增

- 模板设计器、画布、属性面板和预览工作流
- 页面、文本、图片、表格、条码、二维码、页码和标签网格
- 模板新建、保存、重开、删除、清空本地库、导入导出和元素预设
- 本地模板库与可替换的 REST 仓储
- 预览和打印共用运行时渲染

## 已知限制

- 当前模板主要保存在浏览器本地，重要模板请先导出 JSON 备份
- 不包含 PDF 或图片导出、静默打印、云打印、设备参数控制、账户同步和协作
- 建议在桌面 Chrome 或 Edge 中使用，并在原生打印对话框中选择实际尺寸

## 升级说明

这是第一个版本，没有旧版迁移步骤。后续版本会在这里继续补充新增、优化、修复和限制说明。
