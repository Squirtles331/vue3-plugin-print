# 浏览器打印验收（v0.1）

在创建 `v0.1.0` 标签前，使用最新桌面 Chrome 和 Edge 各执行一次以下清单。真实打印机、纸张和驱动差异不能由自动化测试替代。

## 前置条件

- 使用 `npm ci` 后执行 `npm run verify` 并记录通过结果。
- 准备一台可用打印机，或使用系统“另存为 PDF”验证浏览器分页。
- 使用项目自带起始模板与脱敏 JSON，不使用真实业务数据。

## 每个浏览器的检查项

- 新建任一起始模板，调整纸张、方向、边距和背景；保存、关闭后重新打开，确认内容一致。
- 保存第二份模板，删除其中一份，再执行“清空本地模板库”；确认当前画布未改变、其他站点数据未被清除。
- 导出模板 JSON 后重新导入；确认会加载为可编辑模板并保留版本化结构。
- 输入嵌套 JSON：确认文本、图片占位、条码、二维码、表格数组和多标签字段按路径解析；缺失字段应显示错误/占位，而非示例业务值。
- 使用长表格验证自动分页、表头/表尾设置和页码；确认预览与打印输出的元素、尺寸和页数一致。
- 打开原生打印对话框，选择 100%/实际尺寸并关闭浏览器页眉页脚；确认打印预览不含选框、辅助线、属性面板或编辑器工具栏。
- 对一个实际目标纸张执行输出，记录打印机型号、纸张、驱动缩放设置和任何不可打印边距调整。

任何阻塞项都必须在标签前修复或明确从支持范围中移除。
