## Why

The project is ready to be presented as an open-source v0.1 application, but its README opens directly with a dense feature list. A clearer entry point helps new users understand what it is, where to try it, and the deliberate limits of the first release before they install or evaluate it.

## What Changes

- Add a compact project introduction, release scope, and first-screen navigation to the README.
- Make the online-demo, source-installation, usage, browser-printing, and contribution sections easier to discover.
- Preserve the existing Chinese-first documentation, English quick start, and explicit v0.1 limits.
- Do not add copied screenshots, branding, badges, claims, or text from other print-designer projects.
